# Enterprise ERP Suite — Frontend

React 19 + TypeScript + Vite + TailwindCSS frontend application for Enterprise ERP Suite.

## Features
- **AI Agentic Mesh View**: Real-time multi-agent orchestration, live telemetry, and evaluation metrics from FastAPI.
- **Enterprise Modules**: Finance & Accounting, Supply Chain & Inventory, HR & Payroll, CRM & Sales Pipeline, Manufacturing & Production.
- **Google Sheets 2-Way Sync**: Live bidirectional syncing with Google Workspace APIs.
- **Role-Based Access Control (RBAC)**: Secure multi-role permission matrix.

## Development

```bash
# Install dependencies
npm install

# Run dev server
npm run dev

# Build production bundle
npm run build
```
